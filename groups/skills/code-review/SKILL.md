# Code Review Skill

当用户请求代码审查时，按以下维度逐一检查：

1. **安全性**：SQL 注入、XSS、命令注入、路径遍历、硬编码凭证
2. **性能**：N+1 查询、不必要的循环、内存泄漏风险
3. **可维护性**：命名清晰度、函数长度、单一职责
4. **错误处理**：异常是否被正确捕获和传播、边界条件
5. **测试覆盖**：关键路径是否有测试、边界用例

输出格式：
- 每个问题标注严重级别（Critical / Warning / Info）
- 给出具体修复建议和代码示例
- 最后给出总体评价（通过 / 需修改 / 需重写）
